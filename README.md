# TeleQueue 🏥
### ระบบบันทึกนัด Telemed ผู้ป่วย หอผู้ป่วยพิเศษปาริฉัตร - หอสงฆ์อาพาธ

ระบบจัดการคิวนัด Telemed ครบวงจร เชื่อมโยงฐานข้อมูล Google Sheets เดิม พร้อมระบบปฏิทิน เช็คสถานะการโทรนัด/ลงบันทึก HosXP และระบบแจ้งเตือนอัตโนมัติเข้ากลุ่ม LINE ด้วย LINE Messaging API

---

## 🌟 ฟังก์ชันหลักของระบบ (Features)

### 1. Dashboard (ภาพรวมระบบ)
- **สรุปตัวเลขนัดหมาย**: นัดวันนี้, นัดทั้งหมด, นัดที่ยังไม่ได้โทร, และนัดที่โทรแล้วพร้อมบันทึก HosXP แล้ว
- **แจ้งเตือนรายการที่ยังดำเนินการไม่ครบ**: แสดงรายการคนไข้วันนี้ที่ยังไม่ได้โทร หรือยังไม่ได้ลง HosXP ทันทีในกล่องแจ้งเตือนสีแดง พร้อมปุ่มยืนยันด่วน
- **สถิติแยกตามแผนก**: แสดงจำนวนนัดหมายแยกตามคลินิก (MED, Sx, Ped, ฯลฯ)
- **ปุ่มด่วนสำหรับแจ้งเตือน LINE**: กดเปิดหน้าต่างแจ้งเตือนได้ทันที

### 2. ปฏิทินนัดหมาย (Interactive Calendar)
- แสดงปฏิทินมุมมอง **รายเดือน (Month)**, **สัปดาห์ (Week)**, **วัน (Day)** และ **รายการ (List)**
- **แยกสีตามสถานะการดำเนินงาน**:
  - 🟢 **สีเขียว**: ดำเนินการครบแล้ว (โทรแล้ว + บันทึก HosXP แล้ว)
  - 🟡 **สีส้ม**: ดำเนินการบางส่วน (เช่น โทรแล้ว แต่ยังไม่ลง Hos หรือกลับกัน)
  - 🔴 **สีแดง**: ยังไม่ได้ดำเนินการ (ยังไม่โทร + ยังไม่ลง Hos)
- **คลิกที่เหตุการณ์**: เปิดหน้าต่างดูรายละเอียดคนไข้ ข้อมูลนัด และกดโทรออกได้ทันที
- **คลิกที่วันที่**: สลับไปยังหน้าคิวเพื่อดูรายชื่อผู้ป่วยที่นัดในวันนั้นทันที
- ตัวกรองแยกตามแผนกและสถานะ

### 3. รายการนัดวันนี้ (Today's Queue)
- แสดงรายชื่อผู้ป่วยนัดประจำวัน พร้อมข้อมูล HN, เลขบัตรประชาชน, แผนก, แพทย์, เบอร์โทร, ชื่อ Line, และหมายเหตุ
- **ปุ่มโทรออกด่วน**: คลิกที่เบอร์โทรศัพท์เพื่อโทรออกผ่านมือถือได้ทันที
- **Checkbox ยืนยันการโทรนัด (TELE)**: บันทึกสถานะทันที พร้อมลงชื่อผู้ดำเนินการและเวลา
- **Checkbox ยืนยันการบันทึก HosXP**: บันทึกสถานะทันที พร้อมลงชื่อผู้ดำเนินการและเวลา
- ตัวเลือกวันที่: สามารถเลือกดูคิวย้อนหลังหรือล่วงหน้าได้ทุกวัน
- ปุ่มพิมพ์ (Print): สำหรับพิมพ์ใบรายชื่อคิวนัดแจกจ่ายในเวร

### 4. จัดการนัดหมาย (Appointment Management & CRUD)
- **ค้นหาแบบ Real-time**: ค้นหาจากชื่อ-สกุล, HN, เลข ปชช., เบอร์โทร, แพทย์ หรือหมายเหตุ
- **เพิ่มนัดหมายใหม่**: ฟอร์มกรอกข้อมูลตามคอลัมน์มาตรฐานของหอผู้ป่วย
- **แก้ไขนัดหมาย**: อัปเดตข้อมูลผู้ป่วยและสถานะ
- **ยกเลิก / ลบนัดหมาย**: พร้อมหน้าต่างยืนยันความปลอดภัย
- ซิงค์ข้อมูลกับ Google Sheets เดิมแบบสองทาง

### 5. LINE Notification (LINE Messaging API)
- **แจ้งเตือนกลุ่ม LINE เมื่อถึงวันนัด**: เพื่อเตือนให้เจ้าหน้าที่ได้โทรเยี่ยมคนไข้
- **สรุปรายชื่อผู้ป่วย**: แสดงชื่อ, HN, แผนก, แพทย์, เบอร์โทร และเหตุผลที่นัด
- **แจ้งเฉพาะรายการที่ยังไม่ได้ดำเนินการ**: กรองเฉพาะรายการที่ยังไม่ได้โทร (`tele == false`)
- **ป้องกันการส่งแจ้งเตือนซ้ำ**: มีระบบ Flag บันทึกลง Google Sheets และตรวจสอบก่อนส่ง
- **พรีวิว LINE Flex Message**: ดูรูปแบบการ์ดข้อความจริงก่อนส่ง
- **ส่งอัตโนมัติประจำวัน (Trigger)**: รองรับการตั้งเวลาส่งอัตโนมัติทุกเช้าใน Google Apps Script

## 🚀 วิธีติดตั้งและใช้งานระบบ

### ขั้นตอนที่ 1: ติดตั้ง Google Apps Script Backend
1. เปิดไฟล์ Google Sheets ของคุณ: [เปิดชีต](https://docs.google.com/spreadsheets/d/1BEQYLBtiMZaCLld6i8mTrn59sKJ75N3kZIiLM7f-lGE/edit?gid=0#gid=0)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ [`gas/Code.gs`](file:///C:/Users/IPD-PA53/.gemini/antigravity/scratch/TeleQueue/gas/Code.gs) ไปวางแทนที่
4. กดบันทึก (ไอคอนแผ่นดิสก์)
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - คำอธิบาย: `TeleQueue API v1`
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(จำเป็นเพื่อให้หน้าเว็บเรียกใช้งานได้)*
6. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)** เก็บไว้

### ขั้นตอนที่ 2: ตั้งค่า LINE Messaging API
1. เข้าไปที่ [LINE Developers Console](https://developers.line.biz/)
2. สร้าง Provider และ Create Channel ประเภท **Messaging API**
3. ไปที่แท็บ **Messaging API** เลื่อนลงมาที่หัวข้อ **Channel access token** แล้วกด **Issue** (คัดลอก Token ไว้)
4. เชิญ LINE Official Account เข้ากลุ่ม LINE ของเจ้าหน้าที่หอผู้ป่วย
5. นำ **Group ID** (สามารถดูผ่าน Webhook หรือดูผ่านเครื่องมือตั้งค่า) มาบันทึกในระบบ

### ขั้นตอนที่ 3: เปิดใช้งานหน้าเว็บ TeleQueue
1. เปิดหน้าเว็บ `index.html` หรือเข้าผ่าน GitHub Pages: `https://swdcph-nurse.github.io/TeleQueue/`
2. คลิกที่ไอคอน **⚙️ ตั้งค่า (Settings)** ที่มุมบนขวา
3. วาง **URL เว็บแอป Google Apps Script**, **LINE Channel Access Token**, และ **LINE Group ID**
4. กด **บันทึกการตั้งค่า** ระบบจะเชื่อมต่อกับ Google Sheets และระบบแจ้งเตือนทันที!

### ขั้นตอนที่ 4: ตั้งเวลาส่งแจ้งเตือน LINE อัตโนมัติทุกวัน
ใน Google Apps Script:
- คุณสามารถรันฟังก์ชัน `setupDailyNotificationTrigger()` หนึ่งครั้งในตัวแก้ไข Apps Script เพื่อให้ระบบตั้งเวลาส่งแจ้งเตือนเข้ากลุ่ม LINE อัตโนมัติทุกเช้า เวลา 08:00 น.
- หรือกดปุ่ม **🔔 แจ้งเตือน LINE** ในหน้าเว็บเพื่อส่งด้วยตนเองได้ทุกเวลา
